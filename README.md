# solc

> DEPRECATION NOTICE
> 
> Since [v0.8.31 the Solidity team provides the official ARM builds](https://github.com/argotorg/solidity/issues/11351#issuecomment-3604448994). Thus this repository is deprecated and is going to discontinue providing new builds since March 1st, 2026.

The main purpose of the repo is to provide linux aarch64 binaries for [alloy-rs/svm-rs](https://github.com/alloy-rs/svm-rs) and eventually for [foundry-rs/foundry](https://github.com/foundry-rs/foundry).
